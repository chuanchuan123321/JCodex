# 圣庙逃亡 (Temple Escape)

一款基于 Vue 3 + Canvas 2D 实现的伪3D无尽跑酷游戏。

## 玩法

- 在神秘古庙中飞奔，躲避石柱、低台、横档与灯笼柱
- 拾取金币积累分数
- 难度随时间递增

## 操作

| 操作 | 键位 |
| --- | --- |
| 切换跑道 | `A` / `D` 或 `←` / `→` |
| 跳跃 | `Space` / `↑` / `W` |
| 暂停 | `Esc` |
| 移动端 | 左右滑动切换跑道，上滑或点击跳跃 |

## 运行

```bash
npm install
npm run dev
```

打开浏览器访问 `http://localhost:5173/` 即可开始。

## 技术

- Vue 3 Composition API
- Canvas 2D 自绘伪3D路面（透视投影 + 滚动虚线）
- 增量难度曲线、粒子特效、HUD 与开始/暂停/结束界面
- 响应式适配（含移动端触控按钮）
